# ハビタマ Androidアプリ 開発仕様書 v0.5

- 更新日: 2026-08-10
- アプリ版: 0.4.2（versionCode 6）

## 1. 今回の変更

初回設定でサンプル選択に加えて任意の行動を作成できるようにする。設定ボタンをシステムバーの安全領域内へ配置する。設定画面ではブラウザやGitHubの画面を経由せず、最新版の確認、APKダウンロード、検証、Androidインストーラー起動までを行える。

### 初回設定契約

- サンプルは初期状態で未選択とし、利用者が必要なものだけ選択する。
- 「自分で行動を作る」から、タイトル、正の整数の目標値、単位、育つ力を入力できる。
- サンプルと自作行動を合わせて最大3件とする。
- 作成済みの自作行動は開始前に削除できる。
- 1件以上を選択または作成した場合だけ「これで始める」を有効にする。
- 設定・戻るボタンを含む上部ヘッダーはステータスバーの内側へ重ねず、48dp以上の操作領域を確保する。

### システムバー表示契約

- アプリ背景は明色のため、ステータスバーの時計・通信・電池アイコンを濃色表示に固定する。
- ナビゲーションバーのシステムアイコンも濃色表示に揃える。

### 目標変更契約

- 既存目標の変更は「今すぐ変更する」の保存完了直後から有効にする。
- 過去日の記録スナップショットは変更しない。
- 今日すでに記録がある場合は、同一トランザクションで今日の記録を新しい目標版へ移し、レコード数を増やさない。
- 育つ力を変更した場合は、今日獲得済みのポイント分類を旧タイプから新タイプへ移す。累積ポイント合計は変えない。
- 今日の実績を再入力した場合は、新しい目標値で再評価し、差分だけを累積ポイントへ反映する。
- v0.4.1以前に翌日適用として予約済みの変更は維持する。新たな変更を保存した場合は、その予約を置き換えて即時反映する。

## 2. 更新情報契約

- 更新情報は`https://github.com/toshiwd/Habitama/releases/latest/download/version.json`からHTTPSで取得する。
- キャッシュを使用せず、接続15秒・読取20秒でタイムアウトする。
- `versionCode`がインストール済みアプリより大きい場合だけ更新可能とする。
- `version`、`versionCode`、`apkUrl`、`sha256`を必須とし、`releaseNotes`は省略可能とする。
- APK URLはHTTPSの`github.com`に限定する。
- 通信失敗、タイムアウト、不正JSONは日本語で表示し、再確認できるようにする。

## 3. APKダウンロード契約

- Android標準の`DownloadManager`を使用し、ブラウザへAPK URLを渡さない。
- ダウンロードはアプリ固有の外部Downloads領域へ保存し、ストレージ権限を要求しない。
- システム通知にも進捗・完了を表示し、設定画面を閉じても継続する。
- 待機、進行率、一時停止、失敗、検証完了を設定画面へ表示する。
- 失敗時は同じ画面から再ダウンロードできる。
- 新しいダウンロードを開始する際は、Habitamaが以前登録した更新ダウンロードだけを削除する。

## 4. 安全性とインストール契約

- ダウンロード完了後、APK全体のSHA-256を計算して`version.json`と照合する。
- 不一致・読取失敗時はインストールボタンを表示しない。
- 検証成功後だけAndroid標準のパッケージインストーラーへcontent URIを渡す。
- Android 8以降で提供元許可がない場合は、Habitama専用の「不明なアプリのインストール」設定を開く。
- 署名鍵は従来のHabitamaリリース鍵を維持し、公開前に直前版と証明書SHA-256を照合する。

## 5. 受入条件

- 公開`version.json`をアプリから取得・解析できる。
- 旧versionCodeのビルドでは更新版とダウンロードボタンが表示される。
- 公開APKが`DownloadManager`で完了し、SHA-256検証後にインストールボタンへ変わる。
- ダウンロード中に設定画面を閉じても処理が継続する。
- 通信失敗・ダウンロード失敗後に再試行できる。
- API 35で提供元許可画面とパッケージインストーラーを開ける。
- 単体テスト、instrumentation、lint、debug/releaseビルド、公開物再取得検証が成功する。

## 6. 非対象

Google Play配布、差分APK、バックグラウンドでの無断インストール、強制更新、クラウド同期、AI、Health Connectは実装しない。
